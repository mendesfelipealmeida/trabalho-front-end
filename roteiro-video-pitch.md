# Roteiro de Video Pitch (Ate 4 minutos)

## 1. Abertura (30-40s)

- Apresente o objetivo: criar um site front-end que consome API publica de desenhos.
- Cite as tecnologias: HTML, CSS e JavaScript puro.
- Informe a API escolhida: Rick and Morty.

## 2. Projeto funcionando (1min)

- Mostre a tela inicial.
- Clique em buscar e exiba os cards carregando.
- Faça uma busca por nome.
- Aplique filtro por status.
- Troque de pagina para mostrar novos resultados.

## 3. Demonstracao tecnica (1min)

- Abra o DevTools no navegador.
- Aba Network: mostre a requisicao para a API.
- Aba Console: explique rapidamente que os dados retornam em JSON.
- Mostre a URL com parametros (`name`, `status`, `page`).

## 4. Explicacao do codigo (1min)

- No HTML: mostre os containers principais (filtros e cards).
- No JavaScript:
  - Funcao que usa `fetch`.
  - Funcao que cria os cards com `createElement`.
  - Uso de `appendChild` para montar a estrutura dinamica.
- No CSS: destaque responsividade e identidade visual.

## 5. Fechamento (20-30s)

- Reforce que os cards sao dinamicos e nao estao fixos no HTML.
- Cite os requisitos atendidos.
- Encerrar com o link do GitHub e agradecimento.
