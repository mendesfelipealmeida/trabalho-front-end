# Trabalho Front-End - API de Desenhos

Projeto criado com `HTML`, `CSS` e `JavaScript` puro, consumindo a API publica de Rick and Morty:
`https://rickandmortyapi.com/`

## Requisitos do enunciado atendidos

- Interface feita sem framework
- Consumo da API com `fetch`
- Cards criados dinamicamente com `createElement` e `appendChild`
- Cada card mostra nome, imagem e status do personagem
- Layout responsivo

## Como executar

1. Abra `index.html` no navegador.
2. Use a busca por nome e o filtro por status.
3. Navegue entre as paginas para carregar novos resultados.

## Estrutura

- `index.html`: estrutura da pagina
- `styles.css`: estilo visual e responsividade
- `script.js`: consumo da API e renderizacao dinamica dos cards

## Publicacao no GitHub Pages (sugestao)

1. Crie um repositorio no GitHub.
2. Envie os arquivos desse projeto.
3. Em `Settings > Pages`, escolha o branch principal e a pasta raiz.
4. Copie o link publicado para entregar junto com a atividade.
